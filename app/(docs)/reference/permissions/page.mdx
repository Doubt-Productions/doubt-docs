# Permissions

Doubt's invite link asks for these permissions. Keep them all ticked: each one is used by a feature, and Doubt asks for nothing it doesn't use.

| Permission | Used for |
|---|---|
| **View Channels** | Seeing the channels it posts in and the ticket channels it creates. |
| **Send Messages** | Welcome, level-up, mod log and ticket messages, and command replies. |
| **Embed Links** | Every Doubt message is an embed. |
| **Attach Files** | Rank cards, welcome cards and ticket transcripts. |
| **Read Message History** | Saving ticket transcripts. |
| **Manage Messages** | Cleaning up messages in the channels Doubt manages. |
| **Manage Server** | Setting up Discord's native [AutoMod](/features/automod) rules with `/automod`. |
| **Manage Nicknames** | Putting `[AFK]` in front of your nickname while you're [AFK](/features/utility#afk). |
| **View Audit Log** | Crediting bans and unbans done in Discord itself (not with `/ban`) to the right moderator in the case. |
| **Manage Channels** | Creating and deleting ticket channels. |
| **Manage Roles** | Welcome and reward roles, and the permissions on each ticket channel. |
| **Kick Members** | `/kick` |
| **Ban Members** | `/ban` and `/unban`, and lifting temporary bans. |
| **Timeout Members** | `/timeout` and `/untimeout` |

If you untick one of these, the rest of Doubt keeps working and only that feature stops: without **Manage Nicknames** AFK works without the tag, and without **View Audit Log** a ban done in Discord is logged with the moderator marked as unknown.

**Create Invite** isn't in the invite; it's only used in Doubt's own support server.

<Callout type="note">
Added Doubt before the invite asked for Manage Server, Manage Nicknames and View Audit Log? Either give Doubt's role those permissions in **Server Settings → Roles**, or open [doubtbot.eu/invite](https://doubtbot.eu/invite) again and re-authorise Doubt for your server. Nothing else changes.
</Callout>

## Role order

Discord lets a bot manage only the roles and members below its own highest role. Put Doubt's role:

- above every role it should give (welcome and level reward roles), and
- above the members it should moderate.

When something is missing, Doubt tells you which permission it lacks and where, instead of failing silently.

## Channel overrides

A channel can take a permission away again with an override. If Doubt can't post the welcome message, the mod log or the ticket panel, check that channel's **Permissions** tab for a deny on Doubt's role or `@everyone`.

## Discord intents

Doubt asks Discord for the **Server Members** intent (to welcome members and give join roles). It does not read members' messages: for levelling and AFK it only notes who posted where. Message text is only read to save ticket transcripts, and only while Discord has approved Doubt's **Message Content** access. Doubt has no prefix commands.
