# Commands

Every Doubt command is a slash command: type `/` in Discord and pick it from the list. This list is generated from the bot itself, so it matches what you see in Discord.

The label on the right is the permission a member needs by default. Server admins can change who sees each command in **Server Settings → Integrations → Doubt**; Doubt still checks the real permission when the command runs. **Everyone** means any member can use it.
