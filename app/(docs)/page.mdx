# Your server, <span className="grad-text">without a doubt.</span>

Doubt is a Discord bot for moderation with cases, Discord's own AutoMod, tickets with transcripts, welcome messages, levelling and a small economy. You set it up with `/setup` in Discord or on the [dashboard](https://dash.doubtbot.eu), and everything works with slash commands.

## What Doubt does

| Feature | In short |
|---|---|
| [Moderation and cases](/features/moderation) | `/warn`, `/timeout`, `/kick` and `/ban` (also temporary). Every action is a numbered case, with an optional mod log and a DM to the member. |
| [AutoMod](/features/automod) | Turns on Discord's native AutoMod rules for spam, invites, mass mentions and word lists, and logs every hit. |
| [Tickets](/features/tickets) | A panel members open private tickets from, with Claim and Close buttons and a saved transcript. |
| [Welcome and join roles](/features/welcome) | A welcome message with placeholders, and roles for new members and new bots. |
| [Levelling](/features/levelling) | XP for chatting, rank cards, a leaderboard, level-up messages and reward roles. |
| [Economy](/features/economy) | A wallet and bank per server, `/beg`, and coins for voting on top.gg. |
| [Utility](/features/utility) | AFK, server and user info, avatars and an embed creator. |
| [Reports](/features/reports) | Report a member, a message or a server to Doubt's own staff. |

Moderation, AutoMod, reports and tickets are free for every server. [Premium](/features/premium) adds extras such as custom ticket topics, XP boosts, scheduled messages and a custom bot look.
