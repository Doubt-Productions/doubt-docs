# Reports

Reports go to **Doubt's own staff**, not to the server's moderators. Use them when someone misuses Doubt or breaks Discord's rules in a way the server itself can't or won't handle. For problems in your server, contact its moderators or open a ticket there.

## How to report

- `/report user user reason`: report a member.
- **Report message**: right-click a message → **Apps** → **Report message**, then describe what happened. Doubt includes the text of that message (up to 1,000 characters) with the report.
- `/report server reason`: report the server you're in for misusing Doubt.

You can't report yourself or a bot, and you can send one report a minute.

## What happens next

Doubt's staff review each report and mark it resolved or dismissed. The person you reported is never told who reported them. Handled reports are deleted 30 days later.

<Callout type="warning">
In an emergency, or for anything that breaks Discord's own rules, also report it to Discord: right-click the message or user → **Report**, or use [Discord's report form](https://dis.gd/report).
</Callout>
